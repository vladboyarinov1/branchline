# Branchline

Нативный Git-клиент для macOS 14 и новее. Универсальная сборка работает на Apple Silicon и Intel.

Тёмное оформление использует цвета GitHub Dark Default из [Primer](https://github.com/primer/primitives), версия 11.10.0.

## Начало работы

1. Откройте образ и перетащите Branchline в «Программы». При обновлении замените прежнюю копию.
2. Выберите одну или несколько папок с Git-репозиториями. Папки можно перетащить в окно. «Открыть демо» создаёт отдельный проект с локальным remote.
3. В панели **Commit** выберите файл для просмотра diff. Отметьте нужные файлы в **Changes** и **Unversioned Files** и нажмите Commit. Если вы собираете коммиты через Stage и Unstage, выберите **Git-индекс** в меню панели. Push показывает ветку назначения.

Нужен Git из Command Line Tools (`xcode-select --install`) или Homebrew. Branchline использует настройки Git, хуки и настроенные помощники HTTPS или SSH.

## Знакомые сочетания macOS

| Клавиши | Действие |
| --- | --- |
| `⌘0` | Показать или скрыть панель Commit |
| `⌘1` | Показать или скрыть дерево файлов проекта |
| `⌘9` | Показать или скрыть Git Log |
| `⌥F12` | Показать или скрыть терминал проекта |
| `⌘K` | Перейти к сообщению коммита |
| `⌘⌥K` | Commit and Push |
| `⌘⇧K` | Push |
| `⌘T` | Update Project (fast-forward) |
| `⌘D` | Show Diff |
| `F7`, `⇧F7` | Следующее или предыдущее изменение |
| `⌃⇧→`, `⌃⇧←` | Следующий или предыдущий файл |
| `⌘⌥A` | Изменить отметку выбранного файла или выполнить Stage в режиме Git-индекса |
| `⌘⌥Z` | Rollback неиндексированных изменений с подтверждением |
| `⌃⌥M` | Amend локального коммита |
| `⌃V`, `⌘⇧A` | VCS Operations и Find Action |
| `⌘F` | Поиск в Git Log |
| `⌘O`, `⌘W` | Открыть репозитории или закрыть текущую вкладку |
| `⌘⇧[`, `⌘⇧]` | Переключить проекты |

Функциональные клавиши могут требовать удержания `fn`. Справка по клавишам доступна в меню **Git → Keyboard Shortcuts**.

## Работа с Git

- Ветка в панели Branches открывает её историю. Кнопка текущей ветки и контекстное меню содержат Checkout, Compare with Current, создание, переименование, безопасное удаление слитой локальной ветки, Merge и Rebase.
- Git Log поддерживает поиск по сообщению и SHA, фильтр по автору и Show History для файла с отслеживанием переименований. Контекстное меню обычного коммита позволяет сделать Cherry-pick или Revert Commit.
- В режиме сравнения рядом перетащите центральный разделитель, чтобы изменить ширину колонок. Двойной щелчок возвращает равную ширину. Branchline запоминает положение.
- В сборке приложения код в diff набран [JetBrains Mono NL](https://www.jetbrains.com/ru-ru/lp/mono/). Подсветка синтаксиса работает на видимых строках и отключается в меню **Вид → Подсветка синтаксиса в diff**.
- При конфликте исправьте файл в редакторе, откройте **Git-индекс** в панели Commit, добавьте исправленные файлы и нажмите Continue. Abort показывает подтверждение.
- В Stash можно сохранить и применить снимок. В Worktrees можно открыть существующее рабочее дерево в отдельной вкладке.
- Панель **Project** показывает дерево файлов рабочей копии, включая скрытые и игнорируемые файлы. Содержимое папок загружается при раскрытии. У изменённых файлов можно посмотреть diff, у остальных доступны открытие в приложении по умолчанию и переход в Finder.
- Открытые вкладки, избранные ветки и черновики коммитов сохраняются локально. Каждая вкладка держит свои фильтры и выбранный файл во время работы.
- Терминал открывается в корне текущего репозитория. «+» добавляет сессию. Скрытие панели и переключение проектов оставляют сессии открытыми до закрытия проекта или приложения.

## Сборка из исходников

Для сборки нужен Xcode 27 или новее (Swift 6.4). Терминал использует [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm).

```sh
./Scripts/package.sh ./dist --dmg
```

Для сборки под архитектуру текущего Mac добавьте `--arch native`. Скрипт создаёт локальный DMG с ad-hoc подписью.

Для локального обновления завершите Branchline, откройте новый DMG и замените копию приложения в «Программах». Открытые проекты, настройки и черновики коммитов хранятся отдельно от приложения.
