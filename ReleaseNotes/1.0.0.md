Первый публичный выпуск Branchline для macOS 14 и новее.

- История Git с графом веток, поиск коммитов и сравнение файлов.
- Выбор файлов для коммита, Stage, Fetch и Push в одном окне.
- Несколько проектов, дерево файлов и встроенный терминал.
- Сравнение кода с подсветкой и регулируемыми колонками.
